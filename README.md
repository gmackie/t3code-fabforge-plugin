# T3 Code FabForge plugin

Read-only reference plugin for fabrication projects and kit-run status. It uses FabForge's existing workspace-scoped fabrication API and preserves the workspace boundary on every request.

Requested access: explicit FabForge secret access, fixed FabForge network access, and project/thread UI panels. Manifest write-back, production actions, and runner control are intentionally excluded from this proof of concept.
